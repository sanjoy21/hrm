# Laravel Project Name

Rk HRM is a Human Resource Management software made by RK Software (Bangladesh) Limited.

## 🚀 Features

- Admin panel with analytics
- Management panel with analytics
- Employee panel with analytics
- Army panel with analytics
- Location based attendance on OpenStreet Map
- Attendance calendar which shows in time, late attendance and leave
- Monthly attendance report
- Excel data import and export
- Leave application and approval system
- Auto generate appointment letter and NOC
- Keep all track of an employee from joining to resigning
- Generate initial salary sheet after cutting late attendance from salary
- Upload final salary sheet in excel format or manually
- Promotion and demotion inserting
- Project management which also counts in time delivery and late delivery
- Disable profile when someone resigns
- Birthday, notice, warning, application notification

## 🛠️ Built With

- [Laravel 12](https://laravel.com/) - PHP Framework
- MySQL - Database
- Blade - Templating engine
- [AdminLTE v3.2](https://adminlte.io/)
- Installed Maatwebsite package to import excel data into database

## 📦 Requirements

- PHP >= 8.2
- Composer
- MySQL
- Node.js and NPM (for front-end assets)
